🔊 英語ネイティブ音声メーカー

英文を貼り付けて、声を選ぶだけ。ネイティブの音声を無料で作って、MP3で保存できます。

使い方

  1. 英文を貼り付けます。生徒が書いたノートや教科書は「📷 写真で読み取る」で撮影すると、英文を自動で読み取れます。
  2. 「AI音声」か「ブラウザ音声」を選び、声を選びます（▶で試聴できます）。
  3. 「音声を作る」を押すと、1文ずつ音声が作られます。
  4. できあがったら再生したり、MP3・WAVで保存したりできます。
写真の読み取りは、手書きモード（初回約65MB）と活字モード（初回約7MB）から選べます。すべて端末内で処理され、写真が外部に送信されることはありません。
AI音声は初回だけ音声モデル（約90MB）を読み込むので、1〜2分かかります。Wi-Fiにつないでから使ってください。2回目からはすぐに使えます。

1英文を入力

読み取りたい英文の部分を指でなぞって囲んでください（囲まなければ全体）。
0 文字 / 0 文
日本語などの英語以外の文字が含まれています。英語の音声では正しく読めないため、英文だけにしてください。

2声を選ぶ

ブラウザ音声の声の種類と音質は、使っている端末によって変わります。この方式ではファイルとして保存できません。保存したいときはAI音声を使ってください。
話す速さ1.0 倍
文と文の間（ポーズ）0.5 秒
リピーティングやディクテーションの音源には、2〜3秒くらいがおすすめです。
くり返し回数（1文ごと）1 回
くわしい設定（AI音声）
高速モードは Chrome / Edge の新しいパソコンで速くなります。動かないときは標準モードに戻してください。

3音声を作る・保存する
